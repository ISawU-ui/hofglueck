# Hofglück

Ein gemütliches Farmspiel im Browser: Felder anlegen, säen, ernten, Tiere halten,
Waren verarbeiten, Aufträge erfüllen und den Hof Level für Level ausbauen.

**Spielen:** https://isawu-ui.github.io/hofglueck/

Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Dann startet das Spiel
randlos wie eine App (im Querformat spielen).
